# Online_Store_Data_Analysis (Creating an Interactive Dashboard using MS Excel)
## Project Objective
The Store wants to create an annual sales report for 2022. So, they can understand their customers and grow sales.

## Questions (KPIs)
- Compare the sales and orders using single chart.
- What are different order status in 2022? 
- Who Made tha highest purchase - Men or Women?
- Which month got the highest sales and orders?
- List top 5 states contributingto the sales?
- Highest selling category?
- Which Channel is contributing maximum to the sales?
- Relation between age and gender based on number of orders.
- Percentage of Total Orders Status.
